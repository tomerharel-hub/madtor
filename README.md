# מד־תור · Madtor

מפה ארצית חיה ואנונימית של זמני ההמתנה בתורים לקלפי. מיזם אזרחי א־מפלגתי.

- `index.html` — דיווח בטאפ אחד, מפה ורשימת יישובים, כפתורי שיתוף
- `admin.html` — ניהול: מחיקה והורדת CSV/JSON (רק למנהלים ב-`admins/`)
- `firestore.rules` — כללי הגישה (להדביק ב-Firebase Console ← Firestore ← Rules)
- `llms.txt`, `api.html`, `data.json`, `robots.txt` — גישה פתוחה לסוכני AI ולמפתחים
- `.github/workflows/deploy.yml` — פריסה ל-GitHub Pages ותמונת נתונים כל ~5 דקות
